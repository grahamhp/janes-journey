# Jane's Journey

A phone-first, step-by-step guide for working abroad safely, saving money, and coming home strong.

- **Journey**: 8 stages, 43 steps with checkboxes, points, levels and badges
- **Fit check**: 11 private questions (age, experience, preferences) that hide paths that don't fit
- **Paths**: cruise ships, Maldives resorts, US seasonal H-2B, Japan SSW (hotel), Korea EPS, Gulf hotels (on hold), plus paths to avoid
- **My jobs**: track agencies and applications, with DMW checks for each
- **Money**: savings calculator that subtracts living costs, start-up costs and money sent home
- **Safety**: golden rules, offer checker, surprises nobody tells you, tap-to-call hotlines, what to do in trouble

Progress is saved in the phone's browser. A backup code (gear icon) can be copied into a message and restored later. Works offline after the first visit.

Facts checked 13 October 2026. Rules change, so always confirm with the DMW (dmw.gov.ph, hotline 1348).

To edit content, change the `STAGES`, `PATHS`, `AVOID`, `RULES`, `QUIZ` and `CALLS` lists near the top of the `<script>` in `index.html`. If you change files, bump `CACHE` in `sw.js` (e.g. `v2`) so phones get the update.
